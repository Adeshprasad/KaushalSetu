1. Executive Summary & Overview

1.1 Application Vision & Mission

KaushalSetu (कौशल सेतु — "Bridge of Skills") is a production-grade full-stack civic portal engineered specifically for rural youth, informal workers, and vocational tradespeople across India. The platform bridges the divide between unorganized, colloquial, hands-on trade skills (such as welding, motorcycle repair, tailoring, solar panel installation, masonry, plumbing, and mobile repair) and formal livelihood opportunities.

1.2 Core Value Propositions

  • Low-Literacy & Vernacular Accessibility: Multilingual interface supporting Hindi, English, Bengali, Odia, and Tamil, paired with browser-native Web Speech API voice input and colloquial natural language understanding.
  • Deterministic Matching Engine: Transparent skill matching computing qualification overlap percentages, matched skills, missing skills, and geographical proximity between candidates and verified trade employers.
  • AI Plain-Language Translation & Grounding: Server-side Gemini 3.8 Flash integrations transforming bureaucratic government scheme rules into 5 simple pillars, conversational Q&A drawers, and plain-language job qualification explainers.
  • Physical World Discovery via Google Maps Grounding: Physical vocational institutes (Government ITIs, PMKVY Pradhan Mantri Kaushal Kendras, Common Service Centres/CSCs, and Polytechnics) located and verified via Gemini Maps tool grounding and deterministic PIN/district lookups.
  • Portable Credentialing ("Kaushal Biodata"): Printable, mobile-optimized A4 Skill Card with generated candidate verification IDs, trade qualifications, wage expectations, and 1-click WhatsApp sharing for local contractors.
  • Dual Data Persistence: Seamless real-time synchronization between local memory stores and Firebase Firestore collections with graceful offline fallbacks.

10. Business Logic & Matching Algorithm

The core matching algorithm is deterministic, ensuring reproducible and verifiable ranking without relying on nondeterministic LLM sorting:

// Base skill match weight: 70%
const skillRatio = normalizedJobSkills.length > 0 ? (matchedSkills.length / normalizedJobSkills.length) : 0;
let baseScore = Math.round(skillRatio * 70);

// Preferred skills bonus: up to 10%
if (job.preferredSkills && job.preferredSkills.length > 0) {
  const prefMatches = job.preferredSkills.filter(ps => normalizedUserSkills.includes(ps.toLowerCase()));
  baseScore += Math.round((prefMatches.length / job.preferredSkills.length) * 10);
}

// Location match weight: 20%
const locationMatch = Boolean(userState && job.state.toLowerCase() === userState.toLowerCase());
if (locationMatch) {
  baseScore += 20;
} else if (!userState) {
  baseScore += 10;
}

const matchPercentage = Math.min(Math.max(baseScore, 0), 100);
